# 算法 / 视觉方向

考核总分 70 分，B 级为 41–50 分。

## 考核任务

- [ ] 1. 识别能量机关“待激活”和“已激活”两种灯效，并在图像中标注结果（10分）。
- [ ] 2. 调用相机并实时显示画面（10分）。
- [ ] 3. 解算待激活靶位姿，计算枪管从当前朝向瞄准目标方块所需转角（10分）。
- [ ] 4. 将算法部署到指定仿真环境，实现各阶段能量机关击打；每完成一个阶段 10 分，共 40 分。

## 推荐推进顺序

1. 先跑通相机采集与实时显示，固定分辨率和帧率。
2. 采集并标注待激活/已激活灯效数据，建立可复现测试集。
3. 完成检测/分类与图像标注，统计准确率和漏检情况。
4. 标定相机内参，明确靶标几何尺寸和坐标系。
5. 解算靶位姿与瞄准转角，使用已知姿态/距离做误差验证。
6. 接入仿真环境，逐阶段验证击打流程并录制证据。
