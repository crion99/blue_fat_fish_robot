# 3 待激活靶位姿解算与枪管瞄准转角

> 算法中期考核第三部分（10 分）。代码：`algorithm/cpp/`；参数：`configs/{camera,gimbal,target}.yml`；
> 验证程序：`apps/pose_selftest.cpp`（合成）与 `apps/live_view.cpp --pose`（实拍点选）。

## 3.1 任务与判分点

考核要求是两件事：

1. **解算待激活靶位姿**：给出靶面在相机坐标系下的旋转 `R` 与平移 `t`（靶心位置）；
2. **计算枪管从当前朝向瞄准目标方块所需转角**：给出 `Δyaw`、`Δpitch`，云台按此转动后枪管轴线对准靶心。

工程上把它拆成一条完整的链路，任何一环缺失都会在落点上暴露：

```
检测 4 个角点(第一部分) → 去畸变 → PnP 位姿 (R,t) → 相机→云台外参
      → 叠加当前云台姿态 → 枪口偏移 → 目标转角 (ψ*,θ*) → 转角差 (Δψ,Δθ) → 电控/仿真
```

## 3.2 约定（左右手、正方向、单位）

| 坐标系 | 原点/轴向 | 用途 |
| --- | --- | --- |
| `{W}` 世界/车体 | x 前、y 左、z 上 | 最终角度定义域 |
| `{G}` 云台 | 旋转中心；x 沿枪管、y 左、z 上 | 外参基准 |
| `{C}` 相机 | 光心；x 右、y 下、z 沿光轴（OpenCV 习惯） | PnP 输出 |
| `{T}` 靶标 | 靶面中心；x 右、y 上、z 指向相机 | 靶面几何 |

- 云台姿态：`R_g(ψ,θ) = Rz(ψ)·Ry(−θ)`，于是枪管轴线 `e1` 指向 `[cosψcosθ, sinψcosθ, sinθ]`；
- 因此 **yaw 逆时针（向左）为正、pitch 抬头为正**，弧度制，对外输出再转角度制；
- 相机与云台的轴向差异必须在 `R_cam_to_gimbal` 里体现：相机 x(右) → 云台 −y、相机 y(下) → 云台 −z、相机 z(前) → 云台 +x。这一条写错，角度会整体差 90°。

## 3.3 靶面模型与角点顺序（与第一部分的接口）

- 靶面为边长 `L` 的正方形（`configs/target.yml`，默认 150 mm，**最终以规则手册为准**）；
- 角点顺序硬约定：`0 左上、1 右上、2 右下、3 左下`（从相机看过去逆时针），坐标 `(±L/2, ±L/2, 0)`；
- 顺序必须与检测模块完全一致：顺序错一个，PnP 会给出一个“重投影误差也不小”的错误位姿，这类错误在画面上很难肉眼发现，所以两边都写死顺序并各自写测试。

## 3.4 相机模型与标定

针孔 + Brown–Conrady 五参数畸变（`k1,k2,p1,p2,k3`），与 OpenCV 标定输出一致：

$$
x_d = x\,k(r^2) + 2p_1xy + p_2(r^2+2x^2),\quad k(r^2)=1+k_1r^2+k_2r^4+k_3r^6
$$

- 去畸变用不动点迭代（8 次，往返误差 < 1e-9 px，见自检）；
- 标定：棋盘格 9×6、15 mm，20 张左右不同姿态，重投影误差应 < 0.3 px；
- 标定结果直接填 `configs/camera.yml`，代码不重编。

## 3.5 位姿解算

### 3.5.1 初值：平面单应 DLT

靶面共面（z=0），映射 `[X,Y,1] → [x,y,w]` 是单应 `H = [r1 r2 t]`。先对靶面坐标和归一化像点各做 Hartley 归一化（去质心、平均距离缩放到 √2），再解 9 元齐次方程：

- 用 `AᵀA` 的**最小特征值对应的特征向量**求 `h`（自实现 Jacobi 特征分解，避免只为 DLT 引 Eigen/SVD）；
- `H` 分解：`λ = 2/(‖h1‖+‖h2‖)`，`r1=λh1, r2=λh2, t=λh3`，若 `t_z<0` 整体取反（靶必须在相机前方）；
- 旋转用 Gram–Schmidt 正交化，保证 `R ∈ SO(3)` 且 `det=+1`。

### 3.5.2 优化：高斯-牛顿最小化重投影误差

残差 `r_i = π(K, R P_i + t) − u_i`（像素），对 6 维扰动 `[δ; τ]` 求解析雅可比：

$$
J = \frac{\partial \pi}{\partial (x,y)}\cdot\frac{\partial (x,y)}{\partial p}\cdot\big[-\,[p]_\times \;\; I\big],
\qquad \frac{\partial (x,y)}{\partial p}=\begin{bmatrix}1/z&0&-x/z\\0&1/z&-y/z\end{bmatrix}
$$

带 Levenberg 阻尼求解 `(JᵀJ + λ·diag)Δ = −Jᵀr`，接受则 `λ←0.3λ`，失败则 `λ←10λ`。

> **已踩过的坑（值得写进文档）**：`δ` 表示“相机绕光心转动”，更新时必须 `R ← exp(δ)R` **且** `t ← exp(δ)t + τ`。只更新 `R` 时，靶心位置几乎不动，重投影误差下降不了，优化器会在初值附近“磨”几十次迭代仍停在错误极小值上；合成数据的第一版就是这样暴露出“1 px 噪声下位姿错 80°”的。

### 3.5.3 平面二义性

小靶面、近正视时存在两个位姿（镜像解）重投影误差接近。做法：**多初值**（DLT 解、镜像解 `R·Rx(π)`、`Rx(±0.08)`、`Ry(±0.08)`）各自优化，取“所有点在相机前方 + 重投影 RMS 最小”的解。

## 3.6 瞄准转角解算（核心）

### 3.6.1 四步公式

1. 相机→云台头：`p_g = R_cg · t + t_cg`（`t` 即 PnP 的靶心位置）；
2. 头→世界：`u = R_g(ψ_c, θ_c) · p_g`（**必须乘当前姿态**）；
3. 枪口随姿态转动：迭代求解
   $$
   d = u - R_g(\psi,\theta)\,t_{muzzle},\quad
   \psi \leftarrow \operatorname{atan2}(d_y,d_x),\quad
   \theta \leftarrow \arcsin(d_z/\|d\|)
   $$
4. 输出转角：`Δψ = wrap(ψ*−ψ_c)`，`Δθ = θ*−θ_c`，并按机械限位限幅。

迭代 2–3 次收敛（残差 < 1e-9 rad），因为 `|t_muzzle|` 只有几厘米，误差随距离迅速衰减。

### 3.6.2 为什么第 2 步不能省

相机是**装在云台上**的：PnP 得到的 `p_g` 只在“当前姿态”的云台头坐标系里成立。若把它当成世界系里的固定点直接算角度，等于把当前姿态叠加了两次，误差随 `ψ_c` 线性增长（`ψ_c=30°` 时就差几十度）。第一版实现踩过这个坑，是**闭环自检**（按解出的角转过去，看枪管是否真的指向靶心）发现的，这个自检现在固定在 `AimSolver::aimError()` 与自检程序里，残差 5×10⁻¹¹ rad。

### 3.6.3 重力补偿（可选，默认关）

`muzzle_speed > 0` 时启用：水平距离 `d_h = d·cosθ`，飞行时间 `t_f = d_h/(v0·cosθ)`，落点下沉 `h = ½gt_f²`，抬高 `atan(h/d_h)`，迭代两次。真实弹道参数需实测，因此默认关闭，只在需要打远距离时打开。

### 3.6.4 输出与限幅

- 角度单位：内部弧度，报文用角度制；
- 限位：`yaw ±80°`、`pitch −20°~+30°`（`gimbal.yml`），超限时置 `clamped` 标志，电控可选择拒绝执行；
- 报文（ASCII，便于串口调试）：
  ```
  AIM,<Δyaw_deg>,<Δpitch_deg>,<distance_m>,<OK|REJ>
  例：AIM,1.23,-0.45,4.732,OK
  ```
  `REJ` 表示重投影 RMS > 3 px（角点不可信/遮挡），电控应保持当前角度。

## 3.7 验证

### 3.7.1 算法级（已自动化，`ctest` 可重跑）

合成数据：随机位姿（2–8 m、±25° 倾角、随机滚转）→ 带畸变投影 → 加高斯噪声 → 解算 → 与几何真值比较。**真值由无噪声几何正投影直接给出，不依赖 PnP。**

| 角点噪声 | yaw RMS | yaw P95 | pitch RMS | 位姿平移 RMS | 朴素像素法 yaw RMS |
| --- | --- | --- | --- | --- | --- |
| 0.5 px | 0.012° | — | 0.016° | 89 mm | 0.28° |
| 1 px | 0.024° | 0.03° | 0.034° | 186 mm | 0.24° |
| 2 px | 0.048° | 0.06° | 0.063° | 340 mm | 0.24° |

距离扫描（1 px）：2 m→0.026°/24 mm，4 m→0.025°/87 mm，6 m→0.023°/186 mm，8 m→0.025°/342 mm。

结论：
- 角度误差几乎不随距离变化（角度精度由像素精度/焦距决定），**平移误差随距离线性增长**（深度方向由靶面尺寸定标）；
- 与“像素偏移直接当角度”的朴素做法相比，角度精度约高一个数量级——差距来自相机与枪管不同轴的外参补偿。

### 3.7.2 实拍验证（三步，器材便宜）

| 层级 | 方法 | 判定标准 |
| --- | --- | --- |
| 距离 | 靶纸贴在地面标线 2/3/4/5 m，卷尺对照 | 距离误差 < 3% |
| 角度 | 三脚架 + 量角器，偏 ±10°、抬 10° | 3 m 处角度误差 < 1°（落点 < 5 cm） |
| 全链路 | 激光笔绑在枪管轴线，按解算角转动，量光点偏离靶心 | 落点偏差 < 靶面宽度的 1/3 |

若光点总是偏向同一侧，说明 `gimbal.yml` 的外参有系统偏差，用两次测量的残差即可反解修正（不必重新标定相机）。

## 3.8 误差来源与工程建议

| 来源 | 影响 | 对策 |
| --- | --- | --- |
| 角点定位（1 px） | 0.02–0.05° | 亚像素角点/多帧平均 |
| 内参/畸变误差 | 视场边缘 0.1–0.3° | 重新标定，边缘样本入标定集 |
| 相机-枪管外参 | **系统偏差，最致命** | 激光落点法反解；机械上尽量同轴 |
| 云台角度反馈滞后 | 动态时 0.1–0.5° | 时间戳对齐 + 速度前馈 |
| 靶面尺寸假设错 | 距离成比例错 | 以规则手册为准，实测一次 |

## 3.9 局限与后续（与第四部分衔接）

- 靶标尺寸、灯效语义尚未与规则手册核对（仓库缺规则原文）；
- 只解算静态靶；第四部分打旋转靶时，需要在角速度已知的前提下做**提前量**：`ψ_lead = ψ* + ω·(t_latency + t_flight)`，`t_flight ≈ d/v0`；
- 单目在正对、小靶面时姿态不可靠（旋转误差可到几十度），但**瞄准只需要靶心方向**，实测角度精度不受影响；若后续要判靶面朝向，需要更大靶面或双目。
